Fitur Utama
* Kuis Fakta atau Hoax: pemain menjawab F/H untuk beberapa kabar. Soal diulang dengan while-do, continue saat input salah, break saat pemain berhenti dan peringkat ditentukan dengan nested-if.
* Detektor Berita: pengguna menjawab pertanyaan Ya/Tidak tentang ciri berita (for-to-do dan repeat-until), lalu program menyimpulkan tingkat kecurigaan hoax dengan if-then-else.
* Papan Statistik: menampilkan skor tertinggi dan jumlah permainan.
* Tips Anti-Hoax: tips singkat menghindari hoax.
