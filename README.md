## ✨ Fitur Utama

1. **Kuis Fakta atau Hoax**
   Pemain menjawab F/H untuk beberapa kabar. Soal diulang dengan `while-do`, `continue` dipakai saat input salah, `break` saat pemain berhenti, dan peringkat ditentukan dengan nested-if.

2. **Detektor Berita**
   Pengguna menjawab pertanyaan Ya/Tidak tentang ciri berita (`for-to-do` dan `repeat-until`), lalu program menyimpulkan tingkat kecurigaan hoax dengan `if-then-else`.

3. **Papan Statistik**
   Menampilkan skor tertinggi dan jumlah permainan.

4. **Tips Anti-Hoax**
   Tips singkat untuk menghindari hoax.
